# 装机分盘与安装后加域

自动加域设置仅作用于启用该功能后新下发的装机任务，不会改变已有电脑或已有安装任务。

## 一次性准备

1. 默认使用 HTTPS：装机网页、客户端平台地址和 PE 的连接地址均使用 HTTPS，证书须被 PE 和新 Windows 信任。隔离内网暂不配置证书时，可在单个装机方案中勾选“允许隔离内网 HTTP 加域（密码将明文传输）”；账号验证不提供传输加密。已有 HTTP PE 可继续使用，无需仅为此开关重做 ISO。
2. 装机网络通过 DHCP 提供能解析 AD 域的 DNS，并确保新 Windows 能访问域控、系统时间正常。此功能不会修改 DHCP 或网卡 DNS。
3. 填写具备目标 OU 或容器加域权限的 AD 账号。建议使用只委派电脑创建和查询权限的专用账号；平台登录密码不会自动用作加域密码。
4. 编辑装机方案，勾选“按员工工号改名并加入 AD 域”，填写 AD 域 DNS 名称、目标 OU 和加域账号密码。OU 可留空使用域默认的电脑位置；密码留空仅在域和账号未改变时保留原值。

HTTP 许可仅作用于使用该方案新建的任务，默认关闭；服务器若设置了 `PC_DEPLOY_ALLOW_HTTP=False`，方案开关不能覆盖它。以后启用 HTTPS 时，先确认没有未结束的装机任务，再更换平台地址、CA 和 PE 连接配置，并关闭方案的 HTTP 选项。

## 日常使用

在设备工作台选择启用加域的方案，为每台电脑填写员工工号，例如 `WFQ101755`。工号转为大写，支持 1–14 位字母、数字或连字符，不能以连字符开头或结尾；电脑名末尾预留一位用于重名处理。

优先使用原工号作电脑名；平台进行中的任务或域内已有同名电脑时，依次尝试追加 `A`、`B`，直到 `Z`。纯数字工号保持原值，电脑名从追加 `A` 开始，以符合 Windows 命名要求。同批次允许相同工号，最终电脑名分别分配；不会修改员工的 AD 用户账号。

确认页显示序列号、工号、预计电脑名及将处理的磁盘。客户端安装后检查 AD 重名，按需顺延字母；最终电脑名会同步到对应任务和日志。按方案选择以下一种执行方式，不会自动登录员工账号：

- 安装完成后立即自动加域：自动改名、加域、额外重启一次并验证域信任。
- 先完成现场设置，再由平台统一加域：Windows 装好后显示“待统一加域”，可先设置电脑；在任务记录中勾选准备好的电脑，点击“统一加域并重启”，确认已保存设置后才执行。等待期间不额外重启，安装计时停止，也不占安装并发名额。

统一加域须在任务创建后 72 小时内执行，电脑保持联网；超过期限不会自动加域。方案选择仅作用于新任务，不改变已经运行的安装任务。

普通方案不启用此功能时，保持原有安装流程。未做 OOBE 封装的 WIM 仍需首次管理员登录，才能启动安装后步骤；Windows 家庭版不支持加 AD 域。

## 自动分盘

编辑装机方案，选择“自动分盘方案”：单 C 盘，或 C + D 盘。选择 C + D 后填写 C 盘容量，例如 256 GiB；扣除引导和恢复分区后，剩余空间创建 D 盘。此方式重建所选整块硬盘，旧 C/D 数据都会清空，先备份并核对确认页；其他物理硬盘不处理。

需要保留旧 D 盘数据时，选择“仅还原指定 Windows 分区”，并在工作台明确选中 Windows 分区。此方式保留其他分区，不调整 C 盘大小，不自动移动 D 盘数据。

## 查看电脑配置

在“任务记录”点击设备名称，查看该次任务的型号、序列号、电脑名、CPU、内存条、硬盘、网卡/IP/链路速率、显卡、主板和 BIOS。弹窗随页面轮询更新，并标明 PE 或安装后回报及最后上报时间；计划电脑名与实际电脑名分开显示。

PE 先提供硬件快照，安装后回报补充正式电脑名、Windows 版本、域状态及 C/D 分区容量。缺失字段显示“未上报”。完整 PE 配置采集需要新制作包生成的 ISO；旧 PE 仍可执行新任务，并在安装后补充配置。已有旧任务只显示当时保存的信息。

## 查看结果与故障处理

在对应任务的“查看日志”中查看域 DNS、加域、重启验证及失败详情。“安装并加域完成”表示客户端已经回报域身份和安全通道验证通过；可再到 AD 计算机管理核对电脑名及所在 OU。

加域失败显示“系统已安装，加域失败”，不会重新清盘或重复发起加域。原工号及 `A–Z` 后缀都已占用、镜像残留其他域身份或上次加域结果不确定时停止，需人工核对，不自动删除、重置或替换已有 AD 电脑对象。
