# 安装后自动加域

此功能仅作用于启用自动加域方案后新下发的装机任务，不会改变已有电脑或已有安装任务。

## 一次性准备

1. 装机网页、客户端平台地址和 PE 的连接地址均使用 HTTPS。证书须被 PE 和新 Windows 信任；更换平台地址后更新启动介质中的连接配置。仅修改网页地址不够。
2. 装机网络通过 DHCP 提供能解析 AD 域的 DNS，并确保新 Windows 能访问域控、系统时间正常。此功能不会修改 DHCP 或网卡 DNS。
3. 准备专用加域账号，只委派目标 OU 所需的电脑创建和查询权限。不要使用域管理员或复用平台绑定密码。
4. 编辑装机方案，勾选“安装后自动按员工工号改名并加入 AD 域”，填写 AD 域 DNS 名称、目标 OU 和专用账号密码。密码留空仅在域和账号未改变时保留原值。

## 日常使用

在设备工作台选择启用加域的方案，为每台电脑填写员工工号，例如 `WFQ101755`。工号转为大写，支持 1–14 位字母、数字或连字符，不能以连字符开头或结尾；电脑名末尾预留一位用于重名处理。

优先使用原工号作电脑名；平台进行中的任务或域内已有同名电脑时，依次尝试追加 `A`、`B`，直到 `Z`。纯数字工号保持原值，电脑名从追加 `A` 开始，以符合 Windows 命名要求。同批次允许相同工号，最终电脑名分别分配；不会修改员工的 AD 用户账号。

确认页显示序列号、工号、预计电脑名及将处理的磁盘。客户端安装后检查 AD 重名，按需顺延字母；最终电脑名会同步到对应任务和日志。随后执行改名、加域、额外重启一次和域信任验证，不会自动登录员工账号。

普通方案不启用此功能时，保持原有安装流程。未做 OOBE 封装的 WIM 仍需首次管理员登录，才能启动安装后步骤；Windows 家庭版不支持加 AD 域。

## 查看结果与故障处理

在对应任务的“查看日志”中查看域 DNS、加域、重启验证及失败详情。“安装并加域完成”表示客户端已经回报域身份和安全通道验证通过；可再到 AD 计算机管理核对电脑名及所在 OU。

加域失败显示“系统已安装，加域失败”，不会重新清盘或重复发起加域。原工号及 `A–Z` 后缀都已占用、镜像残留其他域身份或上次加域结果不确定时停止，需人工核对，不自动删除、重置或替换已有 AD 电脑对象。
